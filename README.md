# Calorie AI App

Starter project for a calorie tracking application with AI-assisted meal parsing.

## Stack

- Backend: FastAPI
- Database: PostgreSQL
- ORM: SQLAlchemy
- Auth: JWT
- Password hashing: Passlib
- Frontend: Flutter
- Containerization: Docker Compose
- AI: rule-based placeholder parser service for future LLM integration

## iOS note

Frontend API URL is now configured for iOS simulator with `http://127.0.0.1:8000`. For a physical iPhone device, this should be changed to your Mac local network IP.【cite§source0.0】

## Frontend features

- Login page
- Register page
- Dashboard page
- Food list page
- Profile page
- AI meal parse page
- Parsed meal review and save flow
